# Security Policy

## Supported Versions

The supported version is always the latest released version. If you have any
security issues in earlier versions feel free to report them anyway, so that
I can check if they survived into the current version.

## Reporting a Vulnerability

Please report any vulnerability that might endanger users IMMEDIATELY to my
email at bjoernbuettner[AT]bjoern-buettner[DOT]me, I'll react within 24 hours
under almost any circumstances.

Minor vulnerabilities that are unlikely to endanger users should just be
reported as normal bug and treated as such.
